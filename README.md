# NoiROBO Client

Frontend web application for the NoiROBO equipment rental platform.

## Purpose

Provides user interface for browsing equipment, search and filtering, authentication, booking flow, Stripe checkout, and role-based dashboards.

## Live URL

Client : https://noirobo-client-e4mt.vercel.app/
Server: https://noirobo-server.vercel.app/

## Key Features

- Equipment browsing with search, filter, sort, and pagination
- Authentication and role-based access (Renter, Owner, Admin)
- Equipment booking and favorites management
- Stripe checkout flow and payment history
- Renter, owner, and admin dashboards

## Tech Stack

Next.js, React, Tailwind CSS, Better Auth
